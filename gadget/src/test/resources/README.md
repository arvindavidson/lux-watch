# Protocol test vectors

Reference vectors from Meta's [`muse-gadget-sdk`](https://github.com/facebookincubator/muse-gadget-sdk)
(Apache-2.0), checked byte-for-byte by `./gradlew :gadget:test`.
All keys are public synthetic test keys; never provision them into a device.

| File | Origin | Checked by |
|---|---|---|
| `link_pairing_v5.json` | Copied verbatim from the SDK's `linux/tests/vectors/` (commit `693cde9a`) | `BleVectorCheck` (via `PairingCrypto`): P-256 public keys and ECDH from the published scalars, the device-side transcript for `pairing_auth=none`, transcript hash, session secret, mobile tx/rx keys, session id, and opening/sealing the `client_finished` record (nonce + AAD layout, tamper rejection) |
| `noise_vectors.json` | Generated by `gadget/tools/gen_vectors.py` running the SDK's `NoiseXXInitiator`/`NoiseXXResponder` with fixed keys `11`, `22`, `33`, `44` (×32, in draw order: initiator e, responder e, responder s, initiator s) | `Verify`: msg1, msg2 consumption, msg3, first transport ciphertext of `hello-noise-test` |
| `framing_vectors.json` | Generated by `gadget/tools/gen_vectors.py` from the SDK's `_proto`, `envelope` and `framing` modules | `Verify`: varints, int64 field, `POST /chat/stream` service frame, chunk 0 with chunk id `0x123456789ABCDEF` |
| `token_transfer.json` | Generated by `node gadget/tools/token_vector.mjs` with the web page's own `docs/token/token-crypto.js` (Node's WebCrypto, as browsers run it); synthetic token | `TokenTransferTest`: the watch opens the sealed token, joins the 20-byte writes, rejects tampering and other keys |

To regenerate the generated files:

```bash
git clone --depth 1 https://github.com/facebookincubator/muse-gadget-sdk /tmp/muse-gadget-sdk
pip install cryptography
python3 gadget/tools/gen_vectors.py /tmp/muse-gadget-sdk
```

If a file is removed, its check is reported as skipped rather than passed.

`BleVectorCheck` drives `com.luxwatch.gadget.pairing.PairingCrypto`, the same
transcript / key-schedule / record-layer code `BlePairingServer` calls on the
watch, so a regression there fails the test.
